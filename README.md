DeckMix DJ 🎧

Reproductor DJ para Android inspirado en VirtualDJ.

Funciones principales

- 🎵 Dos decks independientes.
- 🎚️ Crossfader para mezclar canciones.
- 🎛️ Ecualizador de bajos, medios y agudos.
- 📂 Cargar música desde el teléfono.
- 🔄 Beat Sync básico.
- 💿 Scratch táctil aproximado.
- ⏱️ Control de BPM y tempo.
- 🔁 Loops y efectos básicos.

Objetivo

Crear una aplicación DJ fácil de usar desde una pantalla táctil Android.

Tecnologías

- Kotlin
- Android SDK
- ExoPlayer

Proyecto personal en desarrollo.
